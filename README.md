# As Crônicas de Eldoria

## 1. Sobre o jogo

As Crônicas de Eldoria é um RPG de tabuleiro desenvolvido em linguagem C. O jogador escolhe uma classe, explora diferentes fases, enfrenta monstros, conquista recompensas e evolui seu personagem até chegar à batalha final.

## 2. História

O mundo de Eldoria está ameaçado por forças demoníacas. Para restaurar o equilíbrio, o herói precisa atravessar três regiões perigosas:

- Floresta Sombria
- Masmorra
- Reino Demoníaco

Cada região possui monstros, desafios e um chefe próprio.

## 3. Classes disponíveis

- **Guerreiro:** personagem com boa resistência e defesa.
- **Arqueiro:** personagem ágil e especializado em ataques.
- **Mago:** personagem com grande inteligência e habilidades mágicas.

## 4. Sistemas do jogo

- Movimentação pelo tabuleiro com dados.
- Combate por turnos.
- Monstros com diferentes níveis de dificuldade.
- Sistema de experiência e evolução de nível.
- Equipamentos e inventário.
- Poções e recuperação de vida.
- Recompensas por derrotar monstros.
- Missões narrativas antes dos chefes.
- Três fases e uma batalha final.

## 5. Como executar

Compile o projeto utilizando GCC:

```bash
gcc rpg.c -o rpg
```

Execute:

```bash
./rpg
```
